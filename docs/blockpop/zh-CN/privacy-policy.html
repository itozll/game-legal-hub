方块泡泡（BlockPop）隐私政策

状态：待发布草案（尚未生效）
版本：1.0.0-draft
更新日期：2026-10-28
生效日期：正式发布前确认

1. 适用范围与运营主体

本草案说明方块泡泡当前经典玩法及对应隐私政策网页的信息处理情况。运营主体的法定名称、隐私联系邮箱和目标发行地区尚未提供，须在正式发布前补齐；不能以代码仓库的账户名推定运营主体。本草案不是已生效政策。

游戏可能在浏览器或宿主应用内运行。宿主自身的账号、权限及信息处理不由本游戏控制，应同时阅读实际宿主的隐私政策。各语言版本应保持一致，译文差异不限制适用法律赋予的权利。

2. 游戏使用的信息与目的

为恢复未完成的对局、保存最高分和声音选择，游戏通过运行环境提供的本地存储保存棋盘格状态、待放置方块、分数、连击和未消除次数、方块配色、最高分及声音开关。这些记录用于继续游戏、计算游戏得分和保留声音偏好，不用于建立广告画像。

游戏读取宿主提供的应用语言，以匹配中文、英文、俄语或阿拉伯语；语言不支持或接口不可用时使用英文。当前实现不保存语言偏好，也不使用设备语言替代宿主语言。

当前游戏没有注册、登录、云存档、支付、广告 SDK、独立行为分析或崩溃上报功能。当前实现不主动收集姓名、手机号、通讯录、精确位置、证件、照片、摄像头或麦克风数据，也没有把游戏存档上传至开发者服务器的功能。游戏内的本地形状计算与得分计算不构成对玩家身份的识别。

3. 保存、删除与安全

存档及偏好保存在设备或运行环境提供的本地存储中，通常持续到玩家清除相应站点或宿主游戏数据，或运行环境自行移除数据。卸载、备份和恢复的实际行为取决于平台；本游戏不承诺云端恢复，也不承诺宿主从不备份本地数据。

玩家可在设置中更改声音，并通过浏览器站点数据管理或宿主提供的游戏数据清除功能删除本地记录。删除可能永久丢失对局和最高分。运营方不能远程访问或删除仅存在于玩家本地、未提供给运营方的存档。本地存储不等于匿名化或加密，具有设备或宿主存储访问权限的人可能查看记录。

运营方应根据实际处理采取适当的安全措施，并在正式发布时确认保存期限、处理依据和必要的用户权利流程。任何系统均不能被承诺绝对安全。

4. 宿主、网络请求与政策网页

加载游戏、音频、图片或政策网页会向实际托管服务发出提供内容所必需的网络请求。当前可选的远程计算模块下载未启用；如后续启用，须核实下载来源及其日志处理。资源下载不等于上传游戏存档。实际宿主或托管方可能独立处理账号、设备或网络信息，具体类别、用途、期限、存储地区及跨境处理须在上线前核实，不能据此承诺第三方数据只在本地处理。

本游戏的四语政策阅读页为静态页面，不包含广告、统计脚本、追踪像素或外部字体，也不读取游戏存档。如果网页托管在 GitHub Pages，GitHub 会为安全目的记录并保存访问者 IP 地址。参见 GitHub Pages 数据收集说明 和 GitHub 隐私声明。

5. 请求、未成年人及后续功能

正式发布版本须给出可用的隐私联系渠道。玩家可按适用法律请求访问、更正、删除或其他权利，并就宿主独立处理的信息向该宿主提出请求；具体权利和处理依据须结合实际发行地区确认。如玩家主动联系运营方，运营方只应在处理请求所需及适用法律允许的范围内使用其提供的联系信息和问题内容，不应要求提供无关证件或完整存档。

未成年人应遵守当地和宿主的年龄要求，并在需要时由监护人指导。当前实现没有收集年龄或身份验证功能，不能据此认定所有地区的未成年人保护流程已完成。需要监护人同意的处理，应先完成相应流程，不能把开始游戏当作同意。

若以后新增广告、账号、支付、云存档或分析服务，应先更新本政策、核实接收方和处理范围，并提供适用法律要求的告知与同意安排。

6. 更新与发布核对

重要功能或信息处理发生变化时，应同步更新版本、日期和四语正文，并按适用要求告知玩家。正式生效前须确认运营主体、联系方式、发行地区、实际宿主与托管方、保存和删除安排以及真实生效日期。详见 发布核对说明。
