# سياسة خصوصية بلوك بوب (BlockPop)

الحالة: مسودة للنشر (غير سارية المفعول)
الإصدار: 1.0.0-draft
تاريخ التحديث: 2026-10-28
تاريخ السريان: يُحدَّد قبل النشر الرسمي

## 1. النطاق والجهة المشغّلة

تصف هذه المسودة معالجة المعلومات في النمط الكلاسيكي الحالي من بلوك بوب وصفحات الخصوصية التابعة له. لم تُقدَّم الهوية القانونية للجهة المشغّلة أو بريد التواصل للخصوصية أو مناطق الإصدار، ويجب تأكيدها قبل النشر. اسم حساب المستودع لا يثبت هوية الجهة المشغّلة. هذه ليست سياسة سارية.

قد تعمل اللعبة في متصفح أو تطبيق مضيف. يدير المضيف حساباته وأذوناته ومعالجته المستقلة وفق سياسته الخاصة. يجب أن تتوافق النسخ الأربع، ولا تحدّ اختلافات الترجمة من الحقوق التي يمنحها القانون المنطبق.

## 2. المعلومات المستخدمة وأغراضها

لاستئناف الجولات غير المكتملة وحفظ النتائج وتفضيلات الصوت، تخزّن اللعبة محليًا حالة خلايا اللوحة والقطع المتاحة والنقاط والتتابعات وعدد الحركات دون إزالة وألوان القطع وأفضل نتيجة وإعداد الصوت. توفّر بيئة التشغيل هذا التخزين، وتُستخدم السجلات للعب والتفضيلات لا لبناء ملفات إعلانية.

تقرأ اللعبة لغة التطبيق التي يوفّرها المضيف للاختيار بين الصينية والإنجليزية والروسية والعربية. عند عدم دعم اللغة أو تعذّر الواجهة تُستخدم الإنجليزية. لا تحفظ النسخة الحالية تفضيل اللغة ولا تستبدل لغة المضيف بلغة الجهاز.

لا تتضمن اللعبة الحالية تسجيلًا أو تسجيل دخول أو حفظًا سحابيًا أو مدفوعات أو حزم إعلانات أو تحليلات سلوكية مستقلة أو إرسال تقارير الأعطال. لا تجمع عمدًا الأسماء أو الهواتف أو جهات الاتصال أو الموقع الدقيق أو وثائق الهوية أو الصور أو بيانات الكاميرا والميكروفون. لا توجد وظيفة لرفع سجلات اللعب إلى خادم المطوّر. لا يحدّد حساب القطع والنقاط محليًا هوية اللاعب.

## 3. الاحتفاظ والحذف والأمان

تبقى السجلات والتفضيلات على الجهاز أو في التخزين المحلي الذي توفّره بيئة التشغيل، عادةً حتى يمسح اللاعب بيانات الموقع أو اللعبة لدى المضيف، أو تحذفها البيئة نفسها. يعتمد سلوك إزالة التطبيق والنسخ الاحتياطي والاستعادة على المنصة. لا تضمن اللعبة استعادة سحابية، ولا تضمن أن المضيف لا ينسخ البيانات المحلية احتياطيًا.

يمكن تعديل الصوت وحذف السجلات عبر إدارة بيانات الموقع في المتصفح أو أداة حذف بيانات اللعبة لدى المضيف. قد يؤدي الحذف إلى فقدان الجولة وأفضل نتيجة نهائيًا. لا تستطيع الجهة المشغّلة الوصول عن بُعد إلى سجلات موجودة محليًا فقط ولم تُقدَّم لها أو حذفها. التخزين المحلي لا يعني إخفاء الهوية أو التشفير؛ وقد يرى السجلات من يملك صلاحية الوصول إلى الجهاز أو تخزين المضيف.

قبل النشر يجب تأكيد تدابير الأمان المناسبة وفترات الاحتفاظ وأسس المعالجة وإجراءات الحقوق. لا يمكن ضمان الأمان المطلق لأي نظام.

## 4. المضيف وطلبات الشبكة وصفحات السياسة

يؤدي تحميل اللعبة والصوت والصور وصفحات السياسة إلى إرسال طلبات الشبكة اللازمة لتقديم المحتوى إلى خدمة الاستضافة الفعلية. تنزيل وحدة الحساب البعيدة الاختيارية غير مفعّل حاليًا؛ ويلزم التحقق من مصدرها وتسجيل الطلبات قبل تفعيلها. تنزيل الموارد لا يعني رفع سجلات اللعب. قد تعالج المنصات والمضيفون معلومات الحساب أو الجهاز أو الشبكة بصورة مستقلة. يجب التحقق قبل الإصدار من الفئات والأغراض والفترات ومواقع التخزين والمعالجة الدولية، ولا يُوعَد ببقاء بيانات الأطراف الأخرى محليًا.

صفحات القراءة الأربع ثابتة ولا تتضمن إعلانات أو نصوص تحليلات أو وحدات تتبّع أو خطوطًا خارجية، ولا تقرأ سجلات اللعب. إذا استُضيفت على GitHub Pages فإن GitHub يسجّل عناوين IP للزوار ويحتفظ بها لأغراض الأمان. راجع [جمع البيانات في GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection) و[بيان خصوصية GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## 5. الطلبات والقاصرون والميزات المستقبلية

يجب أن توفّر السياسة المنشورة وسيلة تواصل فعّالة للخصوصية. يمكن للاعب طلب الوصول أو التصحيح أو الحذف أو غيرها من الحقوق المتاحة وفق القانون المنطبق، والتواصل مع المضيف بشأن معالجته المستقلة. يجب تأكيد الحقوق وأسس المعالجة بحسب مناطق الإصدار. عند التواصل طوعًا، ينبغي استخدام معلومات الاتصال ووصف المشكلة بالقدر اللازم والمسموح قانونًا فقط، دون طلب وثائق غير مرتبطة أو نسخة كاملة من السجل.

على القاصرين الالتزام بمتطلبات العمر المحلية ومتطلبات المضيف، وبإرشاد وليّ الأمر عند الحاجة. لا تجمع النسخة الحالية العمر ولا تتحقق من الهوية؛ وهذا لا يثبت اكتمال متطلبات حماية الأطفال في جميع المناطق. يجب الحصول على موافقة وليّ الأمر المطلوبة قبل المعالجة المعنية، ولا يحل بدء اللعب محلها.

قبل إضافة الإعلانات أو الحسابات أو المدفوعات أو الحفظ السحابي أو التحليلات، يجب تحديث السياسة والتحقق من الجهات المستلمة ونطاق المعالجة وتقديم الإشعارات وترتيبات الموافقة المطلوبة.

## 6. التحديث والنشر

تتطلّب التغييرات الجوهرية في الميزات أو المعالجة تحديث الإصدار والتاريخ والنصوص الأربع بصورة متسقة، وإخطار اللاعبين عند اللزوم. قبل السريان يجب تأكيد الجهة المشغّلة والتواصل والمناطق والمضيفين والاستضافة وفترات الاحتفاظ والحذف وتاريخ السريان الفعلي. راجع [قائمة التحقق قبل النشر](../publication-notes.html).
