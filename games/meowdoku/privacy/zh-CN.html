Meow Garden 隐私保护指引

更新日期：2026年10月7日

生效日期：2026年10月7日

1 适用范围与开发者

本指引说明 Meow Garden 游戏中的信息处理，以及你访问本隐私协议网站时涉及的第三方服务。我们是 Meow Garden 的开发者，开发者名称：gaoguodong；隐私联系邮箱：joiky@163.com。

本游戏通过宿主应用或平台运行时提供服务。宿主应用自身的账号、权限、广告与其他数据处理，还受其隐私政策约束。本指引不替代宿主应用及广告服务提供方的隐私政策，也不免除我们对自身信息处理的责任。

2 游戏处理的信息及用途

当前游戏代码不提供账号注册、登录、云存档或支付功能，不主动收集昵称、头像、性别、手机号、身份证号码、通讯录、精确位置、相机或麦克风数据，也未接入独立的行为分析或崩溃上报服务。

为提供游戏功能，我们在你的设备或宿主为游戏提供的本地存储中保存以下数据：

  • 游戏进度：当前关卡、已完成关卡、每日挑战完成日期、星星数和提示次数，用于恢复进度和记录奖励。
  • 当前游戏状态：棋盘标记、已放置的猫、剩余生命、当前模式、关卡标识和游戏计时，用于继续未完成的游戏。
  • 游戏设置：声音、动画及语言偏好，用于保留你的设置。

游戏首次启动时读取系统语言设置，以选择合适的界面语言。你可以在游戏设置中修改语言。每日挑战根据设备提供的 UTC 日期在本地选择关卡，无需向我们的服务器发送日期或游戏进度。

当前实现将进度和设置保存在本地，未设置开发者运营的服务器接收这些存档，也不主动将存档发送给广告接口。本地存储不等于匿名化；其他能够访问该设备或宿主存储的人可能看到游戏记录。

3 第三方运行时与广告

游戏在宿主提供 SUD OpenPaaS 运行时的情况下使用其插屏广告及激励视频广告接口。插屏可能在关卡间展示；激励视频用于获取提示或单次复活奖励。你可以不选择观看激励视频；这会影响对应视频奖励的获取。

游戏调用广告创建接口时传入广告位标识，并在内存中处理广告加载、错误及关闭事件。播放完成状态用于判断是否发放奖励；游戏不会通过这些接口主动提交你的本地游戏存档。

宿主应用、运行时及实际广告供给方可能独立处理广告请求、设备及网络相关信息。具体的数据类别、用途、保存期限、处理地区、合法依据和隐私选择，应以你实际使用的宿主应用与广告提供方的告知为准；本项目没有独立核实所有宿主版本和广告供应链的数据处理行为。

平台入口：SUD OpenPaaS。平台公示政策入口：SUD 隐私政策。该入口不能替代实际宿主或广告供给方应提供的具体告知。

如适用法律要求对第三方数据处理、广告个性化或追踪取得同意，应在相关处理开始前取得有效同意。选择观看激励视频并不等于同意个性化广告或跨应用追踪。你可以通过宿主应用及设备提供的隐私控制管理相关权限；本游戏当前未提供独立的广告个性化开关。

4 存储地点与保存期限

游戏进度、当前状态及偏好保存在你的设备或宿主提供的本地存储空间。通常会保留至你清除相关数据、卸载应用，或宿主删除该游戏的存储；具体效果取决于平台的备份、恢复和卸载行为。每日挑战完成日期在读取存档时最多保留最近 366 条记录。

我们不承诺这些本地存档存储于某个国家，也不将第三方服务的数据存储位置表述为开发者本地存储位置。宿主、广告服务及网站托管方可能在你所在国家以外处理信息，相关地点、期限及跨境保障措施由其政策和实际服务决定。

如果你主动联系开发者，我们仅为处理请求使用你提供的联系信息和问题内容，并在处理请求及满足适用法律义务所必要的期间保留；不需要你提供身份证号码或其他与请求无关的信息。

5 使用与对外提供

我们仅为运行游戏、保留进度与偏好、处理广告奖励以及回应你的请求使用上述信息。当前游戏实现不向开发者服务器上传本地存档，也不提供由开发者出售本地存档或对外公开游戏记录的功能。

第三方广告与托管处理见本指引第 3 节和第 8 节。如果我们未来增加信息收集、共享、转让或公开披露，将更新本指引，履行适用的告知义务，并在法律要求时取得你的有效同意。依法必须进行的披露将限于必要范围。

6 你的选择与权利

你可以在游戏设置中修改语言、声音和动画偏好。要删除本地进度，请使用浏览器的站点数据管理，或宿主应用提供的游戏数据清理功能；清除游戏数据可能同时删除进度、奖励和偏好，当前游戏未提供云端恢复。卸载或清理后的实际效果请参照所在平台的说明。

如当地法律适用，你可以请求查阅、复制、更正、删除个人信息、限制或反对处理、撤回同意，或提出投诉。请通过第 10 节的邮箱联系我们。我们会根据适用法律处理请求，仅在确有必要时核实身份。对仅存在于你设备且未提供给我们的存档，我们无法直接远程查看或删除，但可以协助说明本地管理方式。

对宿主、广告服务或 GitHub 独立处理的信息，你也可以直接向相关提供方提出请求，并向有管辖权的数据保护机构投诉。

7 未成年人保护

未成年人应在监护人指导下使用游戏，并遵守宿主应用及所在地区的年龄要求。当前游戏不主动收集年龄，也未设置注册或实名验证功能。游戏不应被理解为已完成所有地区针对儿童的广告与数据保护合规配置。

如适用法律要求监护人同意，我们应在相关处理前取得该同意；不得仅以使用游戏视为监护人同意。如果你是监护人，并认为我们处理了孩子不应被处理的信息，请通过第 10 节联系我们。我们会核实情况，并依法采取删除或其他必要措施。

8 隐私协议网站

本协议静态网页未加入分析脚本、广告 SDK、追踪像素、外部字体或用于记录阅读行为的 Cookie；访问本协议网页不会启动游戏广告或读取游戏存档。通用入口仅在浏览器内使用网址传入的语言或浏览器语言设置，选择对应的协议页面；不保存语言偏好，也不将其发送至开发者服务器。

网站使用 GitHub Pages 托管。GitHub 说明，访问 GitHub Pages 网站时会出于安全目的记录并保存访问者的 IP 地址。此类托管处理由 GitHub 负责，详见 GitHub Pages 数据收集说明 和 GitHub 隐私声明。

点击外部链接后，你的访问将受相应网站的隐私政策约束。

9 安全与指引更新

我们按处理范围采取合理措施保护信息。设备安全、浏览器配置和宿主应用的保护措施也会影响本地存档安全。

当游戏功能或数据处理方式发生变化时，我们会更新本指引及更新日期。涉及法律要求重新告知或同意的变化，将在相关处理开始前完成相应程序；继续使用游戏本身不替代法律要求的同意。

各语言版本描述相同的信息处理范围；如果翻译出现差异，我们将及时更正，且不因此限制适用法律赋予你的权利。
