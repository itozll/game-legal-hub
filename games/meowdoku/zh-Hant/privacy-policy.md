# Meow Garden 隱私保護指引

更新日期：2026年10月7日

生效日期：2026年10月7日

## 1 適用範圍與開發者

本指引說明 Meow Garden 遊戲中的資訊處理，以及你造訪本隱私協議網站時涉及的第三方服務。我們是 Meow Garden 的開發者，開發者名稱：gaoguodong；隱私聯絡信箱：joiky@163.com。

本遊戲透過宿主應用程式或平台執行環境提供服務。宿主應用程式本身的帳號、權限、廣告與其他資料處理，亦受其隱私政策約束。本指引不取代宿主應用程式及廣告服務提供者的隱私政策，也不免除我們對自身資訊處理的責任。

## 2 遊戲處理的資訊及用途

目前遊戲程式碼不提供帳號註冊、登入、雲端存檔或付款功能，不主動蒐集暱稱、頭像、性別、手機號碼、身分證號碼、通訊錄、精確位置、相機或麥克風資料，也未整合獨立的行為分析或當機回報服務。

為提供遊戲功能，我們在你的裝置或宿主為遊戲提供的本機儲存空間中保存以下資料：

- 遊戲進度：目前關卡、已完成關卡、每日挑戰完成日期、星星數和提示次數，用於恢復進度及記錄獎勵。
- 目前遊戲狀態：棋盤標記、已放置的貓、剩餘生命、目前模式、關卡識別碼和遊戲計時，用於繼續未完成的遊戲。
- 遊戲設定：聲音、動畫及語言偏好，用於保留你的設定。

遊戲首次啟動時讀取系統語言設定，以選擇合適的介面語言。你可以在遊戲設定中修改語言。每日挑戰根據裝置提供的 UTC 日期在本機選擇關卡，無須向我們的伺服器傳送日期或遊戲進度。

目前實作將進度和設定保存在本機，未設置開發者營運的伺服器接收這些存檔，也不主動將存檔傳送給廣告介面。本機儲存不等於匿名化；其他能存取該裝置或宿主儲存空間的人可能看到遊戲紀錄。

## 3 第三方執行環境與廣告

在宿主提供 SUD OpenPaaS 執行環境的情況下，遊戲使用其插頁式廣告及獎勵影片廣告介面。插頁式廣告可能在關卡之間顯示；獎勵影片用於取得提示或單次復活獎勵。你可以不選擇觀看獎勵影片；這會影響對應影片獎勵的取得。

遊戲呼叫廣告建立介面時傳入廣告版位識別碼，並在記憶體中處理廣告載入、錯誤及關閉事件。播放完成狀態用於判斷是否發放獎勵；遊戲不會透過這些介面主動提交你的本機遊戲存檔。

宿主應用程式、執行環境及實際廣告供應者可能獨立處理廣告請求、裝置及網路相關資訊。具體資料類別、用途、保存期限、處理地區、合法依據和隱私選項，應以你實際使用的宿主應用程式與廣告提供者的告知為準；本專案未獨立核實所有宿主版本及廣告供應鏈的資料處理行為。

平台入口：[SUD OpenPaaS](https://openpaas.sud.tech/)。平台公布的政策入口：[SUD 隱私政策](https://www.sud.tech/privacy)。此入口不能取代實際宿主或廣告供應者應提供的具體告知。

如適用法律要求對第三方資料處理、廣告個人化或追蹤取得同意，應在相關處理開始前取得有效同意。選擇觀看獎勵影片不等於同意個人化廣告或跨應用程式追蹤。你可以透過宿主應用程式及裝置提供的隱私控制管理相關權限；本遊戲目前未提供獨立的廣告個人化開關。

## 4 儲存地點與保存期限

遊戲進度、目前狀態及偏好保存在你的裝置或宿主提供的本機儲存空間。通常會保留至你清除相關資料、解除安裝應用程式，或宿主刪除該遊戲的儲存；具體效果取決於平台的備份、還原及解除安裝行為。每日挑戰完成日期在讀取存檔時最多保留最近 366 筆紀錄。

我們不承諾這些本機存檔儲存於某個國家，也不將第三方服務的資料儲存位置表述為開發者本機儲存位置。宿主、廣告服務及網站託管者可能在你所在國家以外處理資訊，相關地點、期限及跨境保障措施由其政策和實際服務決定。

如果你主動聯絡開發者，我們僅為處理請求使用你提供的聯絡資訊和問題內容，並在處理請求及滿足適用法律義務所必要的期間保留；不需要你提供身分證號碼或其他與請求無關的資訊。

## 5 使用與對外提供

我們僅為執行遊戲、保留進度與偏好、處理廣告獎勵以及回應你的請求使用上述資訊。目前遊戲實作不向開發者伺服器上傳本機存檔，也不提供由開發者出售本機存檔或對外公開遊戲紀錄的功能。

第三方廣告與託管處理見本指引第 3 節和第 8 節。如果我們未來增加資訊蒐集、分享、移轉或公開揭露，將更新本指引，履行適用的告知義務，並在法律要求時取得你的有效同意。依法必須進行的揭露將限於必要範圍。

## 6 你的選擇與權利

你可以在遊戲設定中修改語言、聲音和動畫偏好。要刪除本機進度，請使用瀏覽器的網站資料管理，或宿主應用程式提供的遊戲資料清除功能；清除遊戲資料可能同時刪除進度、獎勵和偏好，目前遊戲未提供雲端還原。解除安裝或清除後的實際效果請參照所在平台的說明。

如當地法律適用，你可以請求查閱、複製、更正、刪除個人資訊、限制或反對處理、撤回同意，或提出申訴。請透過第 10 節的信箱聯絡我們。我們會依適用法律處理請求，僅在確有必要時核實身分。對僅存在於你裝置且未提供給我們的存檔，我們無法直接遠端查看或刪除，但可以協助說明本機管理方式。

對宿主、廣告服務或 GitHub 獨立處理的資訊，你也可以直接向相關提供者提出請求，並向有管轄權的資料保護機關申訴。

## 7 未成年人保護

未成年人應在監護人指導下使用遊戲，並遵守宿主應用程式及所在地區的年齡要求。目前遊戲不主動蒐集年齡，也未設置註冊或身分驗證功能。本遊戲不應被理解為已完成所有地區針對兒童的廣告與資料保護合規設定。

如適用法律要求監護人同意，我們應在相關處理前取得該同意；不得僅以使用遊戲視為監護人同意。如果你是監護人，並認為我們處理了孩子不應被處理的資訊，請透過第 10 節聯絡我們。我們會核實情況，並依法採取刪除或其他必要措施。

## 8 隱私協議網站

本協議靜態網頁未加入分析指令碼、廣告 SDK、追蹤像素、外部字型或用於記錄閱讀行為的 Cookie；造訪本協議網頁不會啟動遊戲廣告或讀取遊戲存檔。通用入口僅在瀏覽器內使用網址傳入的語言或瀏覽器語言設定，選擇對應的協議頁面；不儲存語言偏好，也不將其傳送至開發者伺服器。

網站使用 GitHub Pages 託管。GitHub 說明，造訪 GitHub Pages 網站時會出於安全目的記錄並保存訪客的 IP 位址。此類託管處理由 GitHub 負責，詳見 [GitHub Pages 資料蒐集說明](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection) 和 [GitHub 隱私聲明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。

點擊外部連結後，你的造訪將受相應網站的隱私政策約束。

各語言版本描述相同的資訊處理範圍；如果翻譯出現差異，我們將及時更正，且不因此限制適用法律賦予你的權利。
